# FUTURE_DS_01
This project is a Business Sales Analytics Dashboard developed using Python, HTML, and CSS. The Python program analyzes business sales data and generates different charts such as line charts, bar charts, pie charts, grouped charts, and stacked bar charts using the Matplotlib library. The dashboard shows monthly revenue trends, top-selling products, regional revenue share, category-wise revenue, profit margins, yearly sales comparison, and quarterly sales performance.
The HTML and CSS code are used to design a professional dashboard webpage. The webpage contains summary boxes, tables, and chart sections to display business performance clearly. This project helps businesses understand sales growth, product performance, regional contribution, and overall profit analysis through visual reports and analytics.
